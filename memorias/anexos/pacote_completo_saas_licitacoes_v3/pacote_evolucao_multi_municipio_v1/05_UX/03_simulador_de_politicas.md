# Simulador de políticas

Antes de publicar uma regra, o proprietário deverá poder preencher um cenário e visualizar:

- regras ativadas;
- cláusulas incluídas;
- cláusulas excluídas;
- template selecionado;
- validações adicionais;
- conflitos;
- versões utilizadas;
- justificativa da decisão.

O simulador reduz o risco de uma política condicional afetar documentos inesperados.
