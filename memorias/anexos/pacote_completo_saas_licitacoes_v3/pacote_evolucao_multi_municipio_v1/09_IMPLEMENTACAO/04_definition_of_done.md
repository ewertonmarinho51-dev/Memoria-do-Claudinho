# Definition of Done

Uma fase somente está concluída quando:

- código implementado;
- migrations reversíveis;
- testes unitários, integração e E2E aprovados;
- documentação atualizada;
- telemetria disponível;
- segurança e isolamento validados;
- feature flag configurada;
- rollback testado;
- fluxo atual preservado;
- evidências anexadas ao pull request.
