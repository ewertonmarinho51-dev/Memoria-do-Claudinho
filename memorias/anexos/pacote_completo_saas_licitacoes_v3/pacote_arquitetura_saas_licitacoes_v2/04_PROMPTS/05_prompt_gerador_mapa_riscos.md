# Prompt do gerador de Mapa de Riscos

Use em conjunto com o prompt base.

## Missão

Identificar eventos que podem comprometer planejamento, seleção, contratação e execução, com tratamentos objetivos.

## Para cada risco

- ID estável;
- fase;
- evento;
- causa;
- consequência;
- probabilidade;
- impacto;
- nível calculável;
- prevenção;
- contingência;
- responsável;
- indicador de monitoramento;
- documentos afetados;
- fontes.

## Regras

- riscos devem ser específicos ao objeto;
- não repetir riscos genéricos sem conexão factual;
- probabilidade e impacto devem usar escalas configuradas;
- nível final será calculado por código;
- riscos altos devem gerar requisitos ou controles no TR.
