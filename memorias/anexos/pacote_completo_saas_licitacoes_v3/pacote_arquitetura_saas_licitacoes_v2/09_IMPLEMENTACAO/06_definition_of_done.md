# Definition of Done

A implementação só está concluída quando:

- fluxo atual foi mapeado;
- chamada real à API está comprovada;
- retrieval trace mostra fontes recuperadas;
- uma chamada principal gera cada documento;
- saída usa schema validado;
- documento canônico é versionado;
- DOCX e PDF seguem o perfil;
- auditor consolida os documentos;
- patch altera apenas caminhos autorizados;
- todos os testes críticos passam;
- feature flags e rollback funcionam;
- logs não expõem segredos;
- documentação de operação foi atualizada;
- CI executa validações;
- existem exemplos antes/depois;
- limitações remanescentes foram registradas.
