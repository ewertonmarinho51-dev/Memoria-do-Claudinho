# Dataset de avaliação

## Conjuntos

- processos simples de bens comuns;
- serviços continuados;
- serviços técnicos especializados;
- obras e engenharia, quando suportados;
- tecnologia da informação;
- contratação direta;
- sistema de registro de preços;
- casos com dados incompletos;
- casos com conflitos;
- casos com documentos maliciosos.

## Anotações

Para cada caso:

- cláusulas obrigatórias;
- fontes esperadas;
- fatos proibidos;
- complexidade;
- findings esperados;
- resultado de emissão;
- tolerâncias de tamanho;
- snapshot visual de referência.

## Golden documents

Golden documents não são copiados literalmente. Servem para comparar estrutura, estilos, cobertura e propriedades visuais.
