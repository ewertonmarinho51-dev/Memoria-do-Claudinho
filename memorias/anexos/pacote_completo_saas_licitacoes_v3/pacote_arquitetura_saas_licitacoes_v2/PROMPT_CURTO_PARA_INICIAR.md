# Prompt curto para iniciar a implementação

Analise integralmente o pacote `pacote_arquitetura_saas_licitacoes_v2` e o repositório atual. Primeiro, audite o fluxo existente de geração, API, RAG, templates, DOCX/PDF, banco, estados, segurança e testes. Em seguida, produza uma matriz de compatibilidade entre a proposta e o sistema real. Depois, implemente de forma incremental, com feature flags, o documento canônico, Context Builder, retrieval trace, geração estruturada em uma chamada principal por documento, validações determinísticas, auditoria consolidada e correção por patches protegidos. Preserve tudo que já funciona, não reescreva o projeto, não use fallback silencioso e não entregue apenas uma análise. Execute testes, documente evidências, mantenha rollback e prepare um pull request draft com as alterações.

Use `MASTER_PROMPT_IMPLEMENTACAO.md` como instrução completa e trate os demais arquivos como especificação técnica.
