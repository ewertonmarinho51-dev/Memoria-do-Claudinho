# Painel de revisão por IA

O painel não exige revisão manual do texto para concluir o caminho automático, mas oferece transparência.

## Exibir

- status geral;
- score;
- fontes consultadas;
- findings por gravidade;
- correções aplicadas;
- documentos impactados;
- versão original e corrigida;
- caminhos alterados;
- validações determinísticas;
- resultado visual;
- hash e data da versão.

## Ações

- corrigir dado ausente;
- reexecutar etapa falha;
- visualizar diff;
- baixar minuta não aprovada com marcação, se permitido;
- emitir versão aprovada;
- registrar justificativa administrativa para exceção, quando a política permitir e houver competência.
