# Mensagens de status e erro

## Boas mensagens

- “O ETP não foi emitido porque o quantitativo diverge do DFD. Confirme o valor correto.”
- “A geração foi interrompida porque a resposta do modelo foi truncada. Nenhum documento final foi criado.”
- “O RAG não encontrou a regulamentação municipal exigida para esta cláusula.”
- “A correção alteraria uma cláusula não autorizada. O patch foi rejeitado.”

## Mensagens proibidas

- “Algo deu errado.”
- “Documento gerado com sucesso” quando houve fallback.
- “100% em conformidade legal.”
- erro técnico com chave, stack trace ou dados sensíveis.
